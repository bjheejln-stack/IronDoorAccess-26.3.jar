# IronDoorAccess 26.3

이 플러그인은 철 문을 설치한 플레이어만 해당 철문을 제어할 수 있게 해주는 기능을 제공합니다.

철 문을 설치한 사람이 우클릭으로 문을 열고 닫을 수 있으며, 추가 권한을 부여한 플레이어도 같은 철문을 열고 닫을 수 있습니다.

## 기능

- 철 문 설치자만 기본 소유권 보유
- 철 문 우클릭으로 열기/닫기
- 설치한 플레이어가 다른 플레이어에게 문 접근 권한 부여 가능
- 추가된 플레이어도 해당 철문을 열고 닫을 수 있음
- 권한 정보는 서버 저장 파일에 저장되어 재시작 후에도 유지
- 권한이 없는 플레이어는 해당 철문을 열 수 없음

## 설치 방법

1. JAR 파일을 서버의 `plugins` 폴더에 넣습니다.
2. 서버를 실행합니다.
3. 철 문을 설치합니다.
4. 해당 철문을 바라본 상태에서 `/추가 [닉네임]` 명령을 입력합니다.
5. 추가된 플레이어는 해당 문을 열고 닫을 수 있습니다.

## 명령어

### `/추가 [닉네임]`
- 설명: 해당 철 문에 다른 플레이어의 권한을 추가합니다.
- 사용 조건: 철 문을 설치한 플레이어만 사용 가능
- 예시:
  - `/추가 홍길동`
  - `/추가 김철수`

## 권한 동작 방식

- 철 문을 설치한 사람 = 소유자
- 소유자는 해당 철문을 언제든지 열고 닫을 수 있음
- 소유자가 `/추가 닉네임`을 입력하면 해당 플레이어에게 권한 부여
- 추가된 플레이어도 해당 철문을 우클릭으로 열고 닫을 수 있음
- 다른 사람은 권한이 없으면 문을 열지 못함

## 다운로드

배포용 JAR 파일:

- `server/plugins/IronDoorAccess-26.3.jar`
- `target/IronDoorAccess-26.3.jar`

## 버전 정보

- 플러그인 버전: `26.3`
- 지원 서버: Paper / Spigot 1.20 계열

## 주의사항

- 철문을 설치한 본인만 권한을 추가할 수 있습니다.
- 철문 권한은 각각의 문마다 별도로 저장됩니다.
- 권한을 추가한 플레이어는 해당 문을 열고 닫을 수 있지만, 다른 문에는 권한이 없습니다.
